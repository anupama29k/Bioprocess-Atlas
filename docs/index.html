Bioprocess Atlas

Measured fermentation runs from published studies, changed one thing at a time, turned into the same set of phenotypes, so the effect of a gene, a temperature or a feed can be compared across labs, organisms and scales.

What it is for

Open upstream bioprocess data is scarce: the largest public benchmark is simulated, and real industrial sets usually keep only harvest-day values. The atlas collects real time courses and puts them in one shape.

compare

Effects you can trust

Every perturbation is measured against its own reference, ideally reactors run the same day, with replicate statistics on every number.

reproduce

Raw file to release in one command

Each table is rebuilt from the unchanged published files. A checksum and the engine version are stamped on every release.

model

Training data for a virtual bioreactor

Set points become doses (°C, vvm, °P, feed rate), the bioprocess version of graded genetic perturbations.

Use it

Load a release

import pandas as pd
eff = pd.read_csv("release/effects.csv")
eff[eff.p_welch < 0.05].sort_values("effect_size_d")

Rebuild from raw files

pip install -r requirements.txt
python -m atlas.build        # → release/
python tests/test_atlas.py   # 13 checks

To add a dataset: put the unchanged files and a README (citation, license, conditions, caveats) in data/raw/<name>/, write one ingester function in atlas/ingest.py, and rebuild. The build refuses variables outside the vocabulary.
